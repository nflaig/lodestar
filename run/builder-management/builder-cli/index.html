builder CLI Command

Run a builder client

Examples​

Base builder command​

Run builder client

./lodestar builder

builder Options​

--dataDir​

Lodestar root data directory

type: string

--network​

Name of the Ethereum Consensus chain network to join

type: string

choices: "mainnet", "gnosis", "sepolia", "hoodi", "plataberget", "chiado", "ephemery", "dev"

default: "mainnet"

--paramsFile​

Network configuration file

type: string

--rcConfig​

RC file to supplement command line args, accepted formats: .yml, .yaml, .json

type: string

example: Options can be written as nested maps or dotted keys

network: hoodi
logLevel: debug
metrics:
  enabled: true
  port: 8008

--supernode​

Subscribe to and custody all data column sidecar subnets

type: boolean

--semiSupernode​

Subscribe to and custody half of the data column sidecar subnets to support blob reconstruction, enabling more efficient data availability with lower bandwidth and storage requirements compared to a supernode.

type: boolean

--logLevel​

Logging verbosity level for emitting logs to terminal

type: string

choices: "error", "warn", "info", "verbose", "debug", "trace"

default: "info"

--logFile​

Path to output all logs to a persistent log file, use 'none' to disable

type: string

--logFileLevel​

Logging verbosity level for emitting logs to file

type: string

choices: "error", "warn", "info", "verbose", "debug", "trace"

default: "debug"

--logFileDailyRotate​

Daily rotate log files, set to an integer to limit the file count, set to 0 (zero) to disable rotation

type: number

default: 5

--beaconNodeUrl​

Url to a trusted beacon node started with --emitPayloadAttributes

type: string

default: "http://127.0.0.1:9596"

--keystore​

Path to a keystore file

required: true

type: string

--keystorePassword​

Path to a file with password to decrypt the keystore from 'keystore' option

required: true

type: string

--builderPubkey​

Builder's expected public key based on the keystore from 'keystore' option

type: string

--assumeBuilderIndex​

Before the Gloas fork, assume this builder index for the deposit the fork onboards, to bid for the first Gloas slot. Verified against the beacon node after the first Gloas block, bidding stops if the registry disagrees

type: number

--assumeBuilderBalanceGwei​

Balance in gwei assumed with 'assumeBuilderIndex' until the beacon node reports the builder, the deposit amount

type: number

--executionFeeRecipient​

Execution address for receiving the payload rewards

required: true

type: string

--requestTimeout​

Timeout in milliseconds for HTTP requests to the beacon node

type: number

default: 10000

--proposerPreferences.urls​

Urls to additional trusted beacon nodes on the same network, polled once per slot for signed proposer preferences the beacon node missed. At most 3 urls

type: string[]

--proposerPreferences.timeout​

Timeout in milliseconds for polling proposer preferences from beacon nodes

type: number

default: 1000

--execution.urls​

Url to the execution client engine API that builds the payloads. The execution client must be kept in sync by a beacon node

type: string[]

default: [ "http://localhost:8551" ]

--execution.timeout​

Timeout in milliseconds for execution engine API HTTP client

type: number

default: 12000

--execution.retries​

Number of retries when calling execution engine API

type: number

default: 2

--execution.retryDelay​

Delay time in milliseconds between retries when retrying calls to the execution engine API

type: number

default: 2000

--jwtSecret​

File path to a shared hex-encoded jwt secret which will be used to generate and bundle HS256 encoded jwt tokens for authentication with the EL client's rpc server hosting engine apis. Secret to be exactly same as the one used by the corresponding EL client.

type: string

--jwtId​

An optional identifier to be set in the id field of the claims included in jwt tokens used for authentication with EL client's rpc server hosting engine apis

type: string

--payload.constructorUrl​

Private zbuilder session RPC URL for incrementally constructed, validated payloads

type: string

--payload.engineUntilSlot​

Use the execution client instead of the session constructor through this proposal slot (inclusive), for the fork transition. Later slots use the constructor exclusively

type: number

--payload.beginReservations​

Use server-issued constructor reservations to recover safely from lost session-begin replies

type: boolean

default: false

--payload.alternateOrderGenerations​

Opt in to exact retained alternate offers with a compatible generation-aware constructor

type: boolean

default: false

--payload.transactionsFile​

Devnet testing: JSON file containing the exact ordered signed transactions to build

type: string

--payload.testingUrl​

Private execution RPC URL exposing the eth and testing namespaces for controlled payload builds

type: string

--payload.outputDir​

Directory in which to save controlled payload build requests and responses

type: string

--payload.dryRun​

Build and capture controlled payloads without publishing bids

type: boolean

default: false

--bidding.updateIntervalMs​

Poll session payload snapshots at this interval in milliseconds; zero disables API bid updates

type: number

default: 0

--bidding.updateCutoffBps​

Stop session updates at this point within the proposal slot, in basis points

type: number

default: 1000

--bidding.maxRevisionsPerSlot​

Maximum new signed revisions per slot across all parents; existing commitments remain recoverable

type: number

default: 256

--bidding.primaryHandoff​

Retain an exact durable primary bid on a validated same-slot alternate branch (requires constructor capability)

type: boolean

default: false

--bidding.alternateBranches​

Build bounded alternate parent snapshots for API and streaming bids

type: boolean

default: false

--bidding.alternateGossip​

Gossip durable alternate bids at the primary deadline (requires retained order generations)

type: boolean

default: false

--bidding.alternateBuildDurationMs​

Maximum construction time per alternate parent snapshot, in milliseconds

type: number

default: 500

--bidding.alternateRefreshBeforeSlotMs​

Target one alternate refresh this many ms before the slot, after primary gossip plus 100 ms; zero disables

type: number

default: 0

--bidding.deferUnusedGossipStages​

Let an unsigned gossip stage wait for a higher bid within its existing window

type: boolean

default: false

--bidding.shareBps​

Share of the payload value offered to the proposer, in basis points

type: number

default: 9000

--bidding.fixedCostGwei​

Fixed amount in gwei deducted from the proposer share of every bid

type: number

default: 0

--bidding.subsidyGwei​

Fixed amount in gwei added on top of the proposer share of every bid, paid from the builder balance

type: number

default: 0

--bidding.subsidyUntilSlot​

Only add the subsidy to bids for proposal slots up to and including this slot, e.g. the first slot of a fork, the subsidy applies to every bid if unset

type: number

--bidding.minValueGwei​

Never bid below this value in gwei

type: number

default: 0

--bidding.maxValueGwei​

Never bid above this value in gwei

type: number

--bidding.gossipIdentitiesFile​

JSON file listing additional registered builder keystores, password files and deadlineBps for staged P2P bids from the same payload session

type: string

--bidding.deadlineBps​

Point within the slot before the proposal slot at which the payload is retrieved and the bid is published, in basis points

type: number

default: 9500

--bidding.getPayloadTimeout​

Timeout in milliseconds for retrieving the payload from the execution client at the bid deadline

type: number

default: 1000

--bidding.minOperatingBalanceGwei​

Do not bid while the builder balance is below this value in gwei

type: number

default: 1100000000

--reveal.cutoffBps​

Do not reveal the payload if the block committing to our bid arrives after this point within its slot, in basis points. Defaults to PAYLOAD_ATTESTATION_DUE_BPS of the network

type: number

--builderApi​

Enable builder API server, proposers can request the published bids from it directly

type: boolean

default: false

--builderApi.port​

Set port for builder API

type: number

default: 18550

--builderApi.address​

Set host for builder API

type: string

default: "127.0.0.1"

--builderApi.publicUrl​

URL proposers reach the builder API at. Proposers must sign their requests with its hostname as auth data unless --builderApi.authData is set

type: string

--builderApi.bidStream​

Enable the experimental authenticated Gloas WebSocket bid stream alongside the HTTP builder API

type: boolean

default: false

--builderApi.orderExposureTokenFile​

File containing a shared 32-byte lowercase hex token for the private order exposure endpoint

type: string

--builderApi.bidStreamAdaptiveTiming​

Adapt bid-stream send deadlines to measured RTT; requires bid streaming and verified end-to-end pong forwarding

type: boolean

default: false

--builderApi.authData​

Auth data agreed with proposers out of band as a hex string, proposers must sign their requests with it. Takes precedence over the hostname of --builderApi.publicUrl

type: string

--builderApi.httpReturnReserveCapMs​

Experimental HTTP reply allowance cap in ms (0-10000). Defaults to request age; a lower cap can improve bids but risks late responses on slower return paths

type: number

--builderApi.httpResponseMarginMs​

HTTP scheduling and serialization allowance in ms (20-1000). Tune independently of the return cap

type: number

default: 50

--metrics​

Enable the Prometheus metrics HTTP server

type: boolean

default: false

--metrics.port​

Listen TCP port for the Prometheus metrics HTTP server

type: number

default: 5065

--metrics.address​

Listen address for the Prometheus metrics HTTP server

type: string

default: "127.0.0.1"
